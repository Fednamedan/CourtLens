# Анализ данных (первые находки)

- Папка `*_electronic` не означает наличие текстового слоя: `ocr_006` (приказ эл) - чистый скан (manifest: textLayer=false).
  Текстовый слой есть только у `writs_electronic` (017-023) и у всех PDF ФССП. Маршрут определяется постранично по содержимому, не по имени папки.
- Эталон: один документ = одна строка, но `соответчики_*` описывают всех должников. Один акт может порождать несколько строк
  (ocr_007/008, 009/010, 017/018, 022/023 - один акт на разных должников, поле `Файл` разное).
- Типы в эталоне: `приказ`, `приказ эл`, `ИЛ`, `ИЛ эл`.
- Даты в эталоне `YYYY-MM-DD`, суммы числом, паспорт `NNNN NNNNNN` строкой, дело_дата - дата дела, а не дата выдачи.
- Базовый Tesseract (rus, 300 dpi, psm 6) на ocr_001/006: суммы, даты, номера дел читаются верно;
  ошибки в цифрах паспорта (`564951` -> `56495]`) и в шапке. Нужна постобработка цифровых полей.
- Сложность: выбор «основного должника» для строки; ИНН физлица есть не во всех актах (в эталоне часто пусто).
